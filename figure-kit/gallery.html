Seven ways to break a page that aren't a flowchart

Every figure in the series so far is a node-and-arrow diagram, because that is the only shape Mermaid draws. Six of the seven below are shapes it cannot. Each one is markup against a shared stylesheet, so the second figure in an article costs about fifteen lines instead of another afternoon.

05 Split panel The obvious design against the shipped one. Every article in this series makes this move at least once.
Two ways to count tokens
Article 6. The first one is what everybody writes first, and it puts a database write on the request path.
Synchronous
Write the usage row before returning
  • Every provider call now owns a database round trip the user waits on.
  • p99 inherits the worst of two systems instead of one.
  • Contention on the hottest table in the system, written by every service.
  • A billing outage becomes a chat outage.
Bounded staleness
Publish the event, read an aggregate
  • Cap-check reads a digest once per turn, p95 ≤ 100ms.
  • Billable events fire and forget onto a queue.
  • One digester writes the audit table. Application code never touches it.
  • Cost: up to 30s of overrun, named on the tin.
06 Annotated code When the argument lives in three specific lines. Quotes a file that already exists in code-samples/.
Where the redelivery gets absorbed
Article 5. Service Bus will hand the same message over twice, so the transition is the dedup.
usp_Task_TryClaim.sql illustrative — the shipped version lives in code-samples/
UPDATE dbo.Tasks
SET Status = 'Running',
ClaimedUtc = SYSUTCDATETIME()
WHERE TaskId = @TaskIdthe gate, not the worker
AND Status = 'Pending';second delivery matches nothing
-- @@ROWCOUNT is the whole answer: 1 means this delivery
-- won the claim, 0 means another one already did.
SET @Claimed = CASE @@ROWCOUNT WHEN 1 THEN 1 ELSE 0 END;no THROW — output param
This is the highest-signal break available and the work is already done. Moving samples out to code-samples/ is what cost the series its cadence; the fix is to quote six to ten lines back in.
