The startup pairing check
A skill is two files in two places. The registry pairs them before the host starts, and refuses to start when it can’t.

When all pair
The tool manifest is built and the service starts. Of the four above, only list-invoices gets that far.
Any one of these
The service does not come up. Not a warning, and not a log line somebody reads later — a deployment cannot proceed past a host that will not start.
No description
export-ledger has a class and no file describing it. The model would be offered a tool with nothing to say what it is for.
No class
archive-ledger is described and nothing implements it. The manifest would advertise a capability that cannot run.
Classification mismatch
mark-disputed: the attribute says Internal, the description says Restricted. Two halves disagreeing about how sensitive the results are.
Write bit disagrees
refund-payment declares category Read and also carries [SkillWrite]. It would route as a write and be filed as a read.
A unit test catches all four earlier and more cheaply. The startup check is the copy nobody can merge around.
